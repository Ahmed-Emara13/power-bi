Where we started

Getting Odoo into Power BI used to depend on a paid connector and a computer that could never sleep.

We used the CData Odoo connector for Power BI. It worked, but it came with costs and weak points that grew with every report.

×

A paid subscription

A product key to renew, or the dashboards stop refreshing.

×

Installed on local Windows PCs

Every person building reports needed the connector set up on their own machine.

×

A gateway that had to stay on

Scheduled refresh in Power BI ran through a data gateway on a local computer. Computer off, figures stale.

×

Outside our control

A third-party product: no way to add what we needed or fix issues ourselves.

The hosting wall

The usual setups expect Power BI to reach into the Odoo server. Shared hosting won’t allow it.

Connecting Odoo to Power BI is normally recommended on a dedicated server with its own public IP address. Odoo.sh and shared multi-tenant servers have no public IP to reach, so that route is closed.

Also true for the web-link mode. When Power BI reads the data instead, it uses the same web address your team already opens Odoo with. No public IP and no database access needed.

How it works

From Odoo screen to Power BI dashboard in five steps.

  1. Connect

    Sign in to Microsoft once, from inside Odoo, and test the connection with one button.

  2. Choose the data

    Pick an app such as Accounting or Sales and every table in it is listed. Or pick exactly the tables you want.

  3. Publish

    Odoo creates the workspace, dataset and tables in Power BI, with the links between them.

  4. Keep it fresh

    Each table refreshes on its own schedule, sending everything or only what changed.

  5. Use the reports

    Build dashboards in Power BI, then open them right inside Odoo.

Features

Everything needed to run Power BI from Odoo, in one module.

Connect in minutes

One Microsoft sign-in, managed from Odoo.

  • Three sign-in options: a Microsoft account, a company app registration, or approval in the browser
  • Workspaces, reports and dashboards synced from Power BI
  • Separate connections per company

Every Odoo app, including ours

Sales, Purchase, Accounting, Inventory, HR, and our custom modules.

  • Select a whole app and all its tables are listed for review
  • Or specific tables, or a single one with filters
  • As many tables as the app needs

Exactly the data you want

Choose the columns, rows and order that go out.

  • Fields, linked details such as a customer’s country, and calculated values
  • Filters, sorting and record limits per table
  • Preview the first 20 rows before sending

Relationships built for you

Odoo’s own links become Power BI relationships.

  • Order to customer, invoice to customer, and so on
  • One click finds the links on an existing dataset
  • Cross-table reports work from day one

Always up to date

Each table refreshes on its own schedule.

  • From every few minutes to once a month
  • Full refresh, or only records changed since last time
  • Export on demand with one button

Power BI reports inside Odoo

Managers open dashboards without leaving Odoo.

  • Import reports and dashboards from any workspace
  • View them embedded in an Odoo screen
  • Open the original in Power BI with one click

Microsoft Fabric ready

For large volumes and real-time analytics.

  • Sync capacities, create Eventhouses and KQL databases
  • Publish tables and load Odoo rows into them
  • Appears only once switched on in Settings

One place to watch it all

A live dashboard and a complete log.

  • A card per workspace, dataset, table, report and dashboard: totals, published, and weekly activity
  • Every operation logged with rows sent, time taken and errors
  • Old log lines cleaned up automatically

Secure by design

Access follows Odoo’s own rules.

  • Two roles: Power BI User and Power BI Administrator
  • Companies kept apart in multi-company setups
  • Web links protected by tokens carrying a user’s permissions, with expiry and instant revoke

Power BI’s limits handled

Exports don’t fail on Power BI’s rules.

  • Rows sent in batches of 10,000
  • Text over Power BI’s 4,000-character cell limit trimmed automatically
  • A warning before a dataset passes 75 tables

Two ways to deliver

Odoo sends the data, or Power BI collects it. Chosen per dataset.

Push

Odoo sends

Odoo delivers the rows to Power BI on every schedule.

Best for
Always-fresh dashboards in Power BI Service
What it needs
Internet access from the Odoo server. Nothing reaches in.
Web link

Power BI collects

Power BI Desktop or Service reads a secure Odoo link, as JSON or CSV.

Best for
Reshaping data in Power Query, and datasets with more than 75 tables
What it needs
Odoo’s normal web address and an access token

Microsoft Fabric Eventhouses use the same outbound delivery as Push.
